# CachyOS Hyprland Pure Setup

Чистовая модульная конфигурация Hyprland на базе CachyOS с расширенным аппаратным функционалом.

## 🚀 Что включено и работает:
- **Параллельный звук по рабочим столам:** независимое одновременное воспроизведение аудиопотоков (ТВ / Ноутбук не глушат друг друга).
- **Синхронизированное разрешение 1080p:** Full HD на всех дисплеях (соотношение 1:1, масштаб 100%).
- **Геометрия экранов:** ТВ расположен сверху (\`auto-up\`), плавный переход мыши и окон.
- **Управление окнами и столами:**
  - \`Win + 1..9, 0\` — переход на рабочий стол 1–10.
  - \`Ctrl + 1..9, 0\` — перемещение активного окна на рабочий стол 1–10.
  - \`Ctrl + ЛКМ\` — Drag & Drop перетаскивание окон между дисплеями.
  - \`Win + Alt + 1..9, 0\` — переключение физических мониторов.
  - \`Super + Enter\` — терминал.
  - \`Super + Q\` — закрытие окна.
- **Клавиатура:** раскладки \`us,ru\`, переключение по \`Alt + Shift\` и \`Win + Space\` с фиксом правого Alt (\`lv3:ralt_alt\`).
- **Unixporn UI:** матовое стекло (Dual-Kawase Blur), анимации Bezier и вращающийся градиент рамок.

## 🛠️ Установка в 1 клик на чистую систему:
\`\`\`bash
git clone https://github.com/gkaims666-ship-it/hyprland-cachyos.git ~/.config/hypr
cd ~/.config/hypr && ./install.sh
